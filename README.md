# LostAndFound

Веб-приложение для поиска потерянных вещей.

Пользователи публикуют объявления о потерянных или найденных вещах с фото и геолокацией, а другие пользователи откликаются и обсуждают детали в комментариях.

## Что умеет

- Регистрация и авторизация пользователей
- Публикация объявлений с фото и координатами на карте
- Просмотр объявлений на интерактивной карте
- Комментарии к объявлениям
- Отклики на объявления (связаться с автором)
- Асинхронная работа с несколькими пользователями
- Загрузка и хранение фотографий
