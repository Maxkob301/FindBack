# FindBack

Мобильное приложение на Flutter для сохранения и поиска местоположений.

## Что умеет

- Сохранение геометки с описанием и фото
- Просмотр всех меток на карте
- Поиск по адресу
- Загрузка фотографий к меткам

## Стек

- Dart
- Flutter
- C++ (нативная часть)
- CMake

## Платформы

- Android
- iOS
- Web
- Windows
- macOS
- Linux
